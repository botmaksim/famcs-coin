# 🏛 Архитектура экосистемы FAMCS Coin

---

## 1. Инфраструктура и DevOps
Единая среда, упакованная в `docker-compose.yml`, готовая к развертыванию на сервере под управлением Debian.
*   **Бэкенд:** Выделенный сервис на **Go** для максимального перформанса, обработки API и вебхуков Telegram.
*   **База данных:** **PostgreSQL 15** для надежного транзакционного хранения экономики, юзеров и настроек.
*   **Фронтенд:** **React + Vite**, собираемый в легковесную статику под управлением Nginx.
*   **Маршрутизация:** Cloudflare для проксирования, защиты от DDoS и красивых поддоменов на базе `mybsu.online`.

---

## 2. Telegram Mini App (TMA)
Главный интерактивный интерфейс внутри мессенджера (разделен на 5 вкладок через Bottom Navigation).

*   **💻 Терминал (Активный фарм):** 
    *   Кликер, стилизованный под написание кода (расходует "Кофе").
    *   Прокачка тапа по технологическому стеку (от Node.js скриптов до C++ движков).
    *   Сбор накопленного пассивного дохода.
*   **🎓 Универ (Магазин):** 
    *   Наем "научной группы" (от первокура до декана) для пассивного фарма.
    *   Покупка уникальных карточек с факультетскими мемами для перманентного процентного буста.
*   **🛡 Сквады (Вертикальные группы):** 
    *   Жесткая привязка игрока к академической группе (например, "11 группа"), объединяющей все курсы.
    *   **Общак (Казна):** Сбор средств на покупку глобального х2 буста на 24 часа для всего сквада.
*   **🔥 События (Викторина и Тотализатор):** 
    *   **Тотализатор:** Ставки на исходы реальных событий факультета.
    *   **Дейли Викторина:** Ежедневная олимпиадная/техническая задача с одной попыткой для получения бонуса.
*   **⚙️ Настройки и DAO:** 
    *   Тумблеры приватности: анонимные переводы, скрытие баланса в лидерборде.
    *   **DAO:** Инвестирование огромной суммы коинов для предложения новой фичи (отправка на премодерацию).

## 3. Telegram-Бот (Социальный движок)
Фоновый процесс, отвечающий за виральность прямо в чатах ФПМИ.

*   **Фантомные чаевые:** Студент отвечает на крутое сообщение командой `/tip 150`. Сервер на Go мгновенно проводит транзакцию, начисляет коины, **удаляет сообщение с командой** и присылает тихое уведомление получателю в личку.
*   **Смарт-Уведомления:** Бот точечно пушит в ЛС только о важном (хранилище полно, ставка сыграла, сквад активировал буст).
*   **Конверсия:** Если чаевые отправлены незарегистрированному пользователю, бот присылает отправителю реферальную ссылку для приглашения.

## 4. Публичный Сайт (`famcscoin.mybsu.online`)
Открытая витрина проекта для браузеров.

*   **Документация:** Лендинг с правилами, лором и Whitepaper экономики.
*   **Лидерборды:** Глобальный рейтинг Сквадов и Топ игроков (анонимы отображаются согласно их настройкам приватности).
*   **Голосование (DAO):** Авторизация через Telegram Login Widget для безопасного голосования за фичи от сообщества.
*   **Зал Славы:** Открытый список Администраторов с их зонами ответственности.

---

## 5. Ролевая Модель и Панель Управления
Секретный роут в Mini App для управления контентом и экономикой, защищенный проверкой Telegram ID.

### 👑 Суперадмин (Максим)
Абсолютный контроль над системой и разрешение конфликтов.
*   **Арбитраж и Возвраты (Refund):** Принудительная отмена любого завершенного события в тотализаторе с автоматическим возвратом ставок всем участникам, если произошел спорный момент.
*   **Пересмотр Викторин:** Возможность изменить правильный ответ во вчерашней/текущей викторине (если в условии была найдена ошибка) и запустить скрипт перерасчета наград.
*   **Компенсации (Bonus Drop):** Функционал ручного начисления/списания коинов любому юзеру для сглаживания багов или выдачи наград за внеигровые заслуги.
*   **Управление Персоналом:** Назначение Админов, а также кнопка **«Отстранить» (Suspend)** — моментальный отзыв всех прав у Админа в случае неадекватного поведения.

### 🛠 Админы (Модераторы)
Студенты-активисты (создатели контента).
*   **Контент-мейкинг:** Добавление новых карточек мемов, пополнение пула задач для викторины.
*   **Управление Событиями:** Создание тотализаторов, закрытие ставок, объявление победившего варианта (применяется правило: *Админы технически не могут делать ставки в тотализаторе*).
*   **Премодерация DAO:** Фильтрация предложенных идей перед выкатом на публичный сайт.
